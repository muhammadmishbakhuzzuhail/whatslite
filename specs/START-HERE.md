# Start here

This is the **single complete project specification folder**. The deliverable is a wireframe-first frontend spec, not an executable Rust app.

1. `README.md` — scope and source-of-truth order.
2. `../PRODUCT.md` and `../DESIGN.md` — product constraints and visual rules.
3. `design-system/` — tokens and component registry; Light/Dark.
4. `wireframes/` — 15 editable SVG diagrams at 1512×982 logical points.
5. `flows/` — 15 Mermaid module interaction diagrams.
6. `specifications/` — 120 UI states, event contracts, component tree, GPUI guidance.
7. `specifications/GPUI-IMPLEMENTATION.md` — architecture and implementation order.
8. `AGENTS.md` — instructions for coding agents.
9. `validation-report.json` — package coverage checks.
10. `FOLDER-TREE.txt` — full directory index.

The agent is responsible for high-fidelity look and feel; no high-fidelity reference images are required. **All data and logins are mocked.**
